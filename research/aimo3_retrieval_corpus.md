# AIMO3 Retrieval Corpus Research
## Datasets for BM25-Searchable Few-Shot Problem Retrieval

**Date:** 2026-03-29
**Goal:** Build a BM25-searchable corpus of solved competition math problems. Given a new AIMO3 problem, retrieve top-k similar solved problems as few-shot examples. AIMO3 problems are IMO/National Olympiad level (110 original problems, algebra/combinatorics/geometry/number theory).

## Dataset Details

### 1. NuminaMath-TIR (HIGHEST PRIORITY for code few-shots)

**HuggingFace:** `AI-MO/NuminaMath-TIR`
**Problems:** 72,500 total (72,401 train + 99 test)
**Solutions:** Tool-Integrated Reasoning (TIR) - Python code + execution, GPT-4 generated
**Difficulty:** Mixed - subset from NuminaMath-CoT, focuses on problems with numerical (integer) outputs
**Sources:** Chinese k12, AMC, AIME, olympiads (filtered subset of NuminaMath-CoT's 9 source categories)
**Format:** Parquet, fields: `problem`, `solution`, `messages` (user/assistant pairs)
**Size:** 148 MB on disk
**License:** Apache 2.0
**Download:**
```python
from datasets import load_dataset
ds = load_dataset("AI-MO/NuminaMath-TIR")
# Also on Kaggle: jorgeplazas/numinamath-tir
```
**Notes:**
- Solutions interleave NL reasoning with Python code blocks (`<llm-code>` tags)
- Problems filtered for numerical integer outputs - aligns well with AIMO3 format
- Best dataset for code few-shot examples: shows how to use sympy/Python to verify
- Overlap with NuminaMath-CoT: this is a filtered subset, ~70K of 860K
- IMO-level subset: filter by `source == "olympiads"` - count unknown but estimated ~5-15K

**Sample structure:**
```json
{
  "problem": "Find all integers n such that...",
  "solution": "Let me think step by step...\n<llm-code>\nimport sympy\n...\n</llm-code>",
  "messages": [{"role": "user", "content": "..."}, {"role": "assistant", "content": "..."}]
}
```

### 2. OpenMathReasoning - TIR Split (BEST for olympiad + code)

**HuggingFace:** `nvidia/OpenMathReasoning`
**Problems:** 306K unique problems from AoPS forums
**Solutions:** 1.72M TIR solutions (multiple per problem) + 3.2M CoT solutions
**Difficulty:** High - sourced from AoPS forums including `aops_c6_high_school_olympiads`
**Sources:** AoPS forums by category (`problem_source` field); `aops_c6_high_school_olympiads` is the olympiad subset
**Format:** Parquet, fields: `problem`, `expected_answer`, `generated_solution`, `problem_source`, `problem_type`, `pass_rate_72b_tir`
**Size:**
- TIR split: **35.7 GB** uncompressed (~15 GB compressed download)
- CoT split: **71.6 GB**
- Additional problems only: 66 MB
- **Total download: 49.6 GB** for all splits
**License:** CC-BY-4.0
**Download:**
```python
from datasets import load_dataset
# Load just TIR split
ds = load_dataset("nvidia/OpenMathReasoning", split="tir")
# Or load additional_problems (66 MB) to get problem list first
ds_problems = load_dataset("nvidia/OpenMathReasoning", split="additional_problems")
```
**Notes:**
- This is the dataset behind NVIDIA's AIMO2 winning solution (NemoSkills, score 34/50)
- `pass_rate_72b_tir` field: use this to filter for problems where TIR succeeds (quality signal)
- For retrieval corpus: filter `problem_source == "aops_c6_high_school_olympiads"` for olympiad-level
- Solutions generated by DeepSeek-R1 - very long (up to 76K chars)
- Deduplication needed if combining with NuminaMath (AoPS problems overlap)
- Practical recommendation: download TIR split only (35.7 GB) and filter to olympiad sources

**Key advantage:** Problems have `used_in_kaggle` boolean - can exclude AIMO competition problems from corpus to avoid contamination.

### 3. NuminaMath-CoT (LARGEST, NL solutions only)

**HuggingFace:** `AI-MO/NuminaMath-CoT`
**Problems:** ~860,000 total
**Solutions:** Chain-of-Thought NL only (no code)
**Sources (9 categories):** `cn_k12`, `olympiads`, `synthetic_amc`, `synthetic_math`, `orca_math`, and others
**Olympiad subset:** ~152K problems from "World Olympiads Data" (IMO, APMO, BMO, national contests) - ~18% of total
**Format:** Parquet, fields: `split`, `source`, `problem`, `solution`, `messages`
**Size:** Large (~3-5 GB estimated for parquet)
**License:** Apache 2.0
**Download:**
```python
from datasets import load_dataset
ds = load_dataset("AI-MO/NuminaMath-CoT")
# Filter to olympiad-level:
olympiad = ds.filter(lambda x: x['source'] == 'olympiads')
```
**Notes:**
- Solutions are NL-only - useful for BM25 retrieval but won't give code few-shots
- The `olympiads` source subset (~152K) is most relevant for AIMO3
- Solutions re-formatted from original PDFs via OCR pipeline, quality varies
- Best use: BM25 index over problem text only, retrieve for context even without code solutions

## Recommended Corpus Construction Strategy

### Tier 1: Core Corpus (download immediately, ~150 MB)

1. **NuminaMath-TIR** (148 MB): Full download. Filter `source == 'olympiads'` for hard subset. These have Python code solutions - essential for code few-shots.
2. **AI-MO/aimo-validation-aime** (<1 MB): All 90 problems with full NL solutions.
3. **lighteval/MATH-Hard** (<10 MB): 3,630 level-5 problems.
4. **Goedel-LM/MathOlympiadBench** (<1 MB): 360 IMO/shortlist problems for problem text.
5. **di-zhang-fdu/AIME_1983_2024** (<1 MB): 933 AIME problems (answers only but useful for retrieval).

**Total Tier 1:** ~160 MB, ~77K problems, immediate value.

### Tier 2: High-value supplements (download selectively)

6. **NuminaMath-CoT olympiads subset**: `source == 'olympiads'` filter - ~152K problems with NL solutions. Full dataset is large; stream and filter.
7. **AI-MO/olympiads**: Full official olympiad problems with official solutions. Download once size is confirmed.
8. **OlympiadBench (lmms-lab)**: 8,476 high-quality olympiad problems.

### Tier 3: Optional (large downloads)

9. **OpenMathReasoning TIR** (35.7 GB): Only worth downloading if cloud/RunPod available. Filter to `problem_source == "aops_c6_high_school_olympiads"`. This is the highest-quality code solution dataset for olympiad problems.

## BM25 Implementation Plan

### Recommended Libraries
- **`bm25s`**: Fastest BM25 in Python (pure Python, sparse matrix), install via `pip install bm25s`
- **`rank_bm25`**: Standard library, simple API

### Corpus Schema (unified jsonl)
```json
{
  "id": "source__original_id",
  "problem": "problem text (for BM25 indexing)",
  "solution_nl": "natural language solution (optional)",
  "solution_code": "python/sympy code solution (optional)",
  "answer": "final answer",
  "source": "numinamath_tir|openmathreasoning|math_hard|aime_1983|...",
  "difficulty": "amc|aime|national_olympiad|imo",
  "competition": "AIME|IMO|USAMO|APMO|...",
  "year": 2024,
  "has_code": true
}
```

### Query Strategy for AIMO3
1. Parse incoming problem: extract key terms, numbers, mathematical objects
2. BM25 query over `problem` field
3. Retrieve top-10 candidates
4. Rerank by: (a) has_code first, (b) difficulty >= aime, (c) BM25 score
5. Format top-3 as few-shot examples in prompt

### LaTeX/Math Term Handling
BM25 on raw LaTeX is noisy. Recommended preprocessing:
- Strip `\frac`, `\sqrt` etc. but keep the operands
- Normalize `\mathbb{Z}`, `\mathbb{N}` to "integer", "natural"
- Keep numerical values (they're strong retrieval signals)
- Tokenize on whitespace + math delimiters

## Critical Observations for AIMO3

1. **IMO-level corpus is thin with code solutions.** NuminaMath-TIR is the best source but many olympiad problems in it are at AIME difficulty. True IMO-level problems with Python solutions are rare.

2. **OpenMathReasoning is the gold standard** but costs 35.7 GB. If RunPod is available, download the TIR split and filter `aops_c6_high_school_olympiads`.

3. **Significant deduplication needed.** AIME 2024 problems appear in NuminaMath, MATH, di-zhang-fdu/AIME_1983_2024, and OpenMathReasoning. Build dedup using problem text hash after normalization.

4. **AIMO3 problem contamination risk.** AIMO3 has 110 original problems (confirmed not in public datasets). OpenMathReasoning has `used_in_kaggle` field - use it to exclude AIMO1/AIMO2 problems from corpus.

5. **NL solutions still valuable for BM25.** Even without code, NL solutions help the model understand approach. Use NuminaMath-CoT olympiads subset (152K problems) for retrieval even if using code for generation.

6. **Winning AIMO2 approach (NemoSkills/NVIDIA):** Used OpenMathReasoning for training, not retrieval. RAG over similar problems was noted as a technique in IMO 2025 open-source winning approaches.
