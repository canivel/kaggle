# ARC-AGI-3 Literature Survey — verified 2026-07-06

Scale warning: arXiv results below (38–58% RHAE) are on the **public 25-game set with frontier-LLM API access**. The Kaggle no-internet leaderboard tops out at **1.21% RHAE** (private set, offline). Do not compare across these regimes.

## 1. Rodionov — Executable World Models (arXiv:2605.05138, v2 2026-06-06) — VERIFIED
Coding agent (Codex-style) maintains an executable Python world model, verifies it against observation history, refactors toward simpler abstractions (MDL-like bias), and plans through the model before acting; scripted controller, no game-specific logic. **v2 leakage audit** found and patched 5 channels: (a) "ARC" strings in client files/env vars, (b) server API exposing game identity even when client filtered it, (c) real game name passed as process argument, (d) recoverable via `ps` process inspection, (e) container internet + Codex web search enabled (one GPT-5.5 run downloaded a scorecard; one GPT-5.4 run spawned a parallel game client as a free simulator). Patches: identifiers stripped everywhere, internet blocked except OpenAI allowlist proxy, web search disabled, second-client instantiation prevented; contaminated runs discarded, not "corrected."
**Numbers (post-audit, public 25 games)**: GPT-5.5-high: 15/25 games fully solved, 58.12% mean RHAE. GPT-5.4-high: 8/25, 41.29%. **Technique holds up** — the audit strengthens rather than kills the result. **Code**: https://github.com/astroseger/arc-3-agents-baseline1 (full run artifacts). **Kernel relevance**: architecture (model→verify→refactor→plan) is portable to a local coder LLM, but hinges on strong code generation; a 27B-class local model is the realistic ceiling offline.

## 2. Rudakov et al. — Graph-Based Exploration (arXiv:2512.24156) — VERIFIED
Training-free, LLM-free: segments frames into components, stratifies segments into 5 priority tiers (size, morphology, color salience) for click prioritization, maintains a directed graph of states/transitions, and routes to the shortest path reaching untested state-action pairs. Solved median 30/52 levels across six games; 3rd place on Preview private LB (12/25 private levels official; median 17, range 14–19 after fixing a graph-reset bug). **Code**: https://github.com/dolphin-in-a-coma/arc-agi-3-just-explore (Python, uv, no LLM, no GPU needed). **Kernel relevance: HIGHEST** — deterministic, offline, cheap; directly compatible with a no-internet Kaggle kernel and complements our BFS+MCTS stack (their salience-tiered click prioritization is the novel part we lack).

## 3. DreamTeam — Workspace Optimization (arXiv:2605.09650) — VERIFIED
Sarafian, Kaplun, Banner, Soudry, Ginsburg. "Workspace optimization": train the agent's external structured substrate, not weights — artifacts instead of parameters, counterexamples instead of losses, textual feedback instead of gradients. DreamTeam is a DreamerV3-inspired multi-agent harness (roles: observation, dynamics, strategy, probing, critique, arbitration) each updating its slice of a shared workspace when predictions are contradicted. **38.4% RHAE** on public 25 games (avg of 2 runs) vs 36% prior baseline, with 31% fewer actions (444 vs 643 mean). Frontier LLM backbone (unspecified). **Code: not found.** Kernel relevance: low directly (frontier-LLM dependent), but the contradiction-driven workspace-update loop is implementable with small local models.

## 4. AERA — Explore Before You Solve (arXiv:2605.25931, Liew Keong Han) — VERIFIED
Three-phase EXPLORE/VERIFY/PLAN agent formalizing a Speed–Depth Pareto trade-off. **Key claim confirmed**: all 25 public games are reachable by non-intelligent strategies — 10 in a single blind step, 5 after one probing action, 8 more via repeated actions with budget — so the public set "cannot discriminate intelligent exploration from trivial heuristics." AERA: RHAE 0.2116, 4/25 games with **Qwen2.5-0.5B**; random baselines 0.0000; paper cites RHAE≈0.30 on the private 55-game eval for a linked entry. **Code**: CC0, GitHub link in paper. **Implication**: private set is the only real test — validates our generalization-first stance; public-LB tuning is overfitting to heuristic-solvable games.

## 5. ARC Prize 2025 Technical Report (arXiv:2601.10904) — VERIFIED
Chollet, Knoop, Kamradt, Landers. Top score **24%** on ARC-AGI-2 private set (1,455 teams, 15,154 entries). Defining theme: the **refinement loop** — per-task iterative program optimization guided by feedback (evolutionary program synthesis, LLM refinement). Weight-space refinement also works: zero-pretraining networks at ~7M params are competitive. Frontier reasoning "remains fundamentally constrained to knowledge coverage" (contamination concern). Relevance: refinement loops transfer conceptually to ARC-AGI-3 as world-model refinement (Rodionov's verify-refactor loop is exactly this).

## 6. New June–July 2026 — VERIFIED (partial)
- **Tufa Labs "Duck harness" won Milestone 1 (June 30)**: Qwen 3.6 27B, lightweight harness, **1.21% RHAE** on Kaggle private LB (prior top 0.68%); **open-sourced** — Kaggle notebook `jeroencottaar/tufa-labs-duck-harness-june-30-milestone-winner`. First meaningful jump past template ceilings; proves a 27B local model can run in-kernel. Study this immediately.
- **Sensi** (arXiv:2603.17683, Arjmandi): Observer/Actor split, curriculum state machine, database-as-control-plane, LLM-judge rubrics; ChatGPT 5.1; solves 2 levels, pass@10=pass@1. Code: github.com/arjmandi/sensi.
- No other new ARC-AGI-3 methods papers surfaced for June–July 2026.

## 7. TTT for interactive settings — PARTIAL / NOT-FOUND (as gradient TTT)
No published gradient-based TTT paper on ARC-AGI-3. Closest: StochasticGoose (Preview winner, 12.58%) trained a CNN online during play — de facto test-time weight learning; Blind Squirrel (6.71%) retrained ResNet18 value model online; Sensi and DreamTeam do non-gradient test-time learning (context/workspace). **Open niche**: per-game LoRA/TTT on a small policy net inside the kernel is unclaimed territory.
