## PLAN-CHANGING

### Prime Agent (Prime Intellect, released 08-05/06, non-arXiv; GitHub PrimeIntellect-ai/prime-agent, MIT)
Open-source "Recursive Language Model" harness: single tool = persistent IPython kernel; sub-agents are function calls (`rlm("sub-task")`, async return); harness state formalized H=(prompt, sub-agents, skills, memory) kept OUTSIDE the active context; `/refine` makes smallest-relevant self-edits with revert-by-ID; crash recovery via session JSONL + kernel snapshot. **ARC-AGI-3: 95.5% with Opus 5 (runs 95.0/95.2/95.5, Best@3 99.97%, 183/183 levels), above the 95.4% human-expert baseline**; gains claimed non-benchmark-specific (long-context suites, EmulatorBench, Factorio).
**Verdict: ADOPT (as design source, not as-is).** We cannot run Opus 5 in the Kaggle offline kernel, but the architecture — program-over-history, state externalization instead of compaction, verified self-refinement — is the strongest published successor-lane blueprint if A22 dies today. Also a competitive-landscape fact for Sunday panel: public ARC-AGI-3 is effectively saturated by harness design, not model scale.

### arXiv:2607.28287 — Tycho: Active Abstraction with Programmatic World Models for ARC-AGI-3 (07-30; not previously processed)
Coding agent that builds/repairs/bypasses executable per-game world models with explicit cost-of-abstraction decisions; separates actionable observations from animation/game-over frames. **183/183 levels with both GPT-5.6 Sol and Opus 5; 61% fewer scored actions than human baselines.**
**Verdict: ADOPT (successor-lane blueprint).** Directly matches our Rodionov exec-sims pivot direction; "active abstraction" (only build the model when it pays) is the per-game-adaptation lane candidate with the strongest evidence. Convergent with Prime Agent: winners externalize state into programs, they don't tune eviction.

### arXiv:2608.01326 — Context Compaction Theory (Tirmazi, Bishop, Mitzenmacher et al., 08-02)
Formalizes compaction as a game equivalent to one-way communication complexity; **proves query sets exist where generation (summarize/digest) needs strictly less budget than selection (eviction/subset-keep)** — selection is provably the weaker strategy class in general.
**Verdict: ADAPT (interpretive frame for today's v2.1 screen).** v2.1 is pure-eviction digest-OFF; this theory predicts pure selection is fundamentally budget-inefficient. It does NOT rescue the lane (our harm tracks compaction pressure itself), but it belongs in the lane post-mortem: if v2.1 fails, the failure is consistent with theory, and reviving any compaction lane should be generation-side, not selection-side.

## Field 2: Compaction / memory management (A22)

- **arXiv:2608.05784 — Activity Frames: Deterministic Screen-Activity Compilation for Agent Memory and Replay (08-06).** Zero-model deterministic pipeline compiles capture stream into typed, bounded frames with evidence pointers back to raw rows; 86x compression, 98.4% query accuracy (vs 66–80% for LLM summaries), deterministic zero-token replay of recurring routines. **ADAPT** — deterministic typed frames + pointer-back beats LLM digests on faithfulness at zero token cost; strongest concrete v3/successor design input for a replay-banking lane on the duck.
- **arXiv:2608.04746 — Scrub Jay Episodic Memory Principles for Agent Memory (08-05).** Type-conditioned temporal decay for external memory eviction improves temporal-reasoning retrieval. **ADAPT (shelf)** — cheap eviction-policy variant (decay rate conditioned on entry type) only if the eviction lane survives today; otherwise moot.
- **arXiv:2608.04843 — MemoryCPT (08-05).** Trainable memory pipeline (query-agnostic distillation + query-aware retrieval) for cost-performance tradeoff. **IGNORE** — requires training; zero-budget rule.
- **arXiv:2608.03137 — Verifiable Memory: local+global verifiers over atomic memory ops (08-04).** Trained with hierarchical credit assignment. **IGNORE** — RL training required; the verifier-gated-memory-ops idea overlaps our planned post-batch verifier (already in R24 pile).
- **arXiv:2608.02508 — RoMeRL: memory-reward trap in self-evolving agent memory (08-03/04).** Learning-based memory disperses feedback; fixed-dim utility states fix it. **IGNORE** (RL setting), but note the "memory-reward trap" as a named failure mode for any future skill-store lane.
- **arXiv:2608.01285 — Stop When Memory Suffices (08-02).** Sufficiency router for early termination, ~25% inference cut. **IGNORE** — retrieval-QA setting, not interactive games.
- **arXiv:2608.00962 — PMMC: prospective multimodal memory compilation (08-02).** Consolidation-time question-conditioned programs. **IGNORE** — LVLM personalization domain; the consolidation-time-verification idea is already covered by our post-batch verifier plan.

## Sunday-panel synthesis (if v2.1 fails today)
Three independent 08-05/06 signals converge: (1) Prime Agent and (2) Tycho both saturate ARC-AGI-3 via **state-externalizing programmatic harnesses** (world-model code + state outside context), not context-window tuning; (3) Context Compaction Theory proves pure selection/eviction is the strictly weaker compaction class. Candidate successor lanes, ranked: **exec-sim / programmatic world-model banking (Tycho-style active abstraction)** > **deterministic typed-frame digest + zero-token replay banking (Activity Frames)** > **replay-verified skill store (2608.06153 + Skill-Use compliance pre-check)** > learned what-to-remember (TTCD, needs GPU builds).
