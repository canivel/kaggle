### arXiv — 08-06 submissions announced 08-07 (not in yesterday's file)

- **2608.06301 — HarnessOpt-Bench: Evaluating LLMs at Harness Optimization.** Benchmark for how well an LLM iteratively improves an agent harness (prompts, tools, control flow, **memory**) under evaluation feedback; 5 frontier LLMs × 4 downstream tasks, gains vary 9–26 pts. Inference-only for the optimizer. **ADAPT** — this is a direct external validation instrument for our KAOS/evolve loop; the finding that optimizer models "separate beyond their coding harnesses" says harness-optimizer choice is itself a decision variable, which is exactly the R24 question.
- **2608.05628 — SkillHEX: Improving Agent Skills via Hypothesis-Driven Autonomous Exploration and Exploitation.** **Inference-only.** Couples hypothesis-driven self-verification with evidence-guided tree search; converts failure hypotheses into **executable tests** that supply dense reward *without extra environment attempts*. 55.9–57.9% on 87 SkillsBench tasks in 5 iterations. **ADOPT-candidate (lane c / lane a hybrid).** This is the cheapest item in the sweep: training-free, and "dense signal without extra env attempts" is precisely our binding constraint (scored-action budget on ARC-AGI-3). It is the mechanism that makes a banking/replay revival affordable.
- **2608.05891 — AppDeltaWorld: Transition-Grounded Delta Code World Model for Mobile GUI Agents.** Predicts the next observation as **executable code deltas** rather than images; SOTA on AndroidLens. Requires training. **ADAPT (design only).** Same family as Tycho/Schema but with a specific idea we lack: model the **delta**, not the full state — cheaper to write, cheaper to verify against the next frame. Directly applicable to a 64×64 grid transition model.
- **2608.06197 — EnvACE: Internalizing Environment Dynamics via World Rehearsal.** Policy generates actions then simulates the environment's response internally, replacing real interaction. Requires end-to-end RL. **IGNORE (build), NOTE (concept).** Training-gated → violates zero-budget rule. But "rehearse in the learned model, spend real actions only to verify" is the action-efficiency argument Tycho already proves at inference time; prefer Tycho's version.
- **2608.06257 — MASS: Multiplayer World Models with Authoritative Shared State.** Disentangles a **Logic Engine** (dynamics) from a **Rendering Engine** (view); scales to 1,024 players × 10,000 steps. Requires training. **ADAPT (architecture only).** The logic/render split is exactly Tycho's state-vars + renderer decomposition arrived at independently from the world-model side — useful convergent evidence for the panel, no build.
- **2608.05863 — Runtime Observability for Heterogeneous Attention Memory.** Inference-only observability contracts over KV caches, sparse selectors, recurrent states; quantifies compression trade-offs and **localizes silent corruption to precise structural boundaries** (12.4M entry reads, zero risk-budget violations). **ADAPT (post-mortem instrument).** This is the closest thing published to a tool that would have answered "*where* did eviction hurt" in A22. Cheap to cite in the lane post-mortem; not a lane.
- **2608.04530 — FocusMem: Factorizing Content, Readout, and Trust in Latent GUI Memory (08-05, missed yesterday).** Separates episodic vs working memory with state-conditioned readout and a **trust gate**; policy frozen, memory trained. Beats fixed-memory baselines on 5 GUI benchmarks. **ADAPT (lane b).** The frozen-policy/trained-memory split is the only shape of "additive typed memory" that is even conceivably compatible with a frozen duck; the trust-gate (memory entries carry a confidence that gates readout) is the additive-memory analogue of our post-batch verifier.
- **2608.05970 — SkillMemo: Expert-guided Skill Memory for Compositional Embodied Manipulation.** MoE trajectory segmentation into latent atomic skills held in episodic memory. Requires training + expert demos. **IGNORE** — robotics domain, demo-supervised, training-gated.
- **2608.05643 — Refining Over Resampling: Test-Time Self-Correction.** Inference-only iterative self-critique per rollout then majority vote; AIME/AMC/MATH500. **IGNORE** — static single-turn math reasoning, no interactive/env component; our prompt-and-vote lane is already known-noise.
- **2608.06144 — FinEvo-Bench: Longitudinal Benchmark for Self-Evolving Agents.** 120 financial tasks; self-evolution gains 9.33–19.37 pts across scaffolds (Letta best, 91.65). **IGNORE** — domain-bound; the only transferable datum is that memory-native scaffolds (Letta) top a *longitudinal* eval, weak support for lane b.

## Implications for R24 (panel Sunday 08-09)

1. **Lane (a) state-externalization / programmatic world models is now the clear front-runner, and today strengthened it on evidence quality rather than on hype.** Three independent teams — Schema (~07-16), Tycho (07-30), Prime Agent (08-05) — converge on "write the mechanism as an executable program, verify against observation, plan inside it." Two of the three have **public code or public traces**. The 08-06 batch adds two independent architectural confirmations from outside ARC (AppDeltaWorld's delta-code transitions, MASS's logic/render split). This is no longer a single-paper bet.

2. **But the headline numbers must be de-rated at the panel.** Prime Agent's 95.5% is unreplicated and self-reported; the *official* ARC Prize leaderboard still reads Opus 5 at 30.2% and excludes harnesses. "Public ARC-AGI-3 is saturated" is true of a self-reported community venue; it says the *design problem* is solved, not that our private-set Kaggle position is hopeless. Do not let the panel over-correct into "we've already lost."

3. **The hard constraint is unchanged and is the real R24 decision.** All three saturating harnesses require a frontier LLM API; our Kaggle kernel is offline with zero budget. So lane (a) cannot be adopted literally — only the *principle* (state lives in verified executable structure outside the context) plus the *artifacts*. Concretely, the one thing this sweep found that we can actually run offline is the **Schema HF trace set + dependency-free scorer**: attachable as a Kaggle dataset, usable to mine transition-model patterns and to sanity-check any local scorer we build. That is a cheap, non-speculative first step regardless of which lane wins.

4. **Lane (c) banking/replay got its enabling mechanism today, not its evidence.** Field 3 remains near-empty two sweeps running — nobody is publishing on replay-banking for episodic agent eval. SkillHEX (2608.05628) supplies the missing piece (executable failure-tests giving dense signal without spending scored actions), but a lane with one enabling paper and no field behind it should be ranked below (a).

5. **Lane (b) additive typed memory is alive but narrowed.** FocusMem is the only shape that survives the frozen-duck constraint (frozen policy, trained memory, trust-gated readout) — and it still needs training, so it is a free-Kaggle-GPU-build item at best. Rank third.

6. **A22 closure is unchallenged.** Zero new compaction-theory work, zero rebuttals to 2608.01326, and the one context-control harness surfaced (Arcgentica) is in the provably-weaker selection/summarization class. Nothing in this sweep argues for reopening the compaction lane. Recommended R24 ranking: **(a) programmatic world models / state-externalization > (c) banking-replay via SkillHEX-style executable failure tests > (b) additive typed memory (FocusMem shape, GPU-build)**.
