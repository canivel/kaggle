**[MAJOR — NEW, potentially fatal to the scheduler leg] (D) The +0.24 best-across EV zeroes the FP loss inconsistently with the proposal's own FP definition —** An FP is defined as "a good run with first clear after t" — i.e., a run with **zero banked clears at trigger time**. Best-across-attempts scoring protects *already-achieved* clears; it cannot bank a clear that the truncated continuation *would have* achieved after action 90 but never did. On that plain reading, the FP loss (−0.242) is charged identically under both scoring semantics, and net best-across at (90, cap 2) is 0.185 − 0.242 + 0.059 ≈ **+0.002 — the same as last-attempt, killing the lever under both semantics and obviating R1 entirely**. The only way FP loss = 0 under best-across is if restart does **not** truncate a shared per-game budget (i.e., each attempt gets a fresh action/wall allowance, so the counterfactual continuation is never destroyed) — but that is a *budget* semantics assumption, distinct from the *scoring* semantics fact-check, and it is stated nowhere. Fix: re-derive the EV table with budget semantics explicit as a second axis (shared vs per-attempt budget), and extend the pre-registered fact-check to resolve both facts before any window is spent.

**[MAJOR — NEW] (E) The Track B mechanism statistic is calibrated against the wrong null —** "P(≥3 events all-spurious) < 0.01" is obtained by cubing the 10.1% per-event false-attribution rate, which conditions on the event *rate* being the treatment-predicted rate — circular. The correct question is: under the null (restarts add nothing), what is the expected count λ₀ of observed "restart-recovered clears"? Your own numbers imply ~13.8 stuck-at-90 runs per 25-game draw, of which 10.1% are games that clear anyway; if those games' fresh attempts re-clear at any substantial rate (they are, by construction, good-mode-capable), λ₀ plausibly approaches 1–1.5 per draw ≈ 2–3 across 2 windows — at which point P(N ≥ 3 | λ₀) is nowhere near 0.01 and the threshold has no discriminative power.
