## Test-time learning / within-episode drift [line 1 / tr87 depth lane]

**No Time Like the Present: Agentic Test-Time Training for LLM Agents (aTTT)**
([arXiv:2607.03441](https://arxiv.org/abs/2607.03441), **Jul 3 — in window, new-to-set via citation trail**)
— adapts model **weights within a single episode** (vLLM runtime-LoRA), not cross-trial like Reflexion.
Central diagnosis: "as trajectories grow, they revisit explored states, repeat failed actions, and lose
strategies that previously worked." Fix = **token-level reweighting** that downweights repeated n-gram
content from prior updates while preserving novel tokens (separates useful self-training from harmful drift
amplification). +5.0 ALFWorld / +4.9 SWE-bench-Lite, 1.9× compute; gains **concentrate where the model
already has competence** ("preserves existing competence rather than teaching new abilities"). **Verdict:
ADAPT (low) → tr87 depth-budget lane, design-only, NO build.** The *mechanism* (LoRA weight updates) is
off-regime — no cloud spend, frozen fork, in-context only. But the **within-episode-drift diagnosis is the
cleanest external statement of exactly what the tr87 revise-loop must defend against**: on the hard-game
frontier at native budget, the failure mode is looping over revisited states / re-failing actions, and the
counter is a *harness-side* dedup signal — surface prior-attempt/failed-action n-grams into the revise-loop
context so the agent doesn't re-emit them. That is the in-context analogue of aTTT's token-reweighting, and
it composes with yesterday's 2607.20972 point (harness deterministically injects the anti-repeat cue on
revise-loop entry). One sentence into the tr87 lane design doc: "revise-loop must inject a prior-failed-action
digest to counter within-episode drift (cf. aTTT 2607.03441); LoRA path out-of-regime." The "gains only where
competence exists" caveat also re-confirms depth events price where the model *can* solve — supports the
depth-lane pricing (+0.19–0.29), not the efficiency channels (~0).

**Test-Time Adaptation for LLM Agents via Environment Interaction**
([arXiv:2511.04847](https://arxiv.org/abs/2511.04847), Nov 2025 / rev Feb 2026 — **out of window**, new-to-set)
— **Dynamics Grounding**: a persona-driven exploration phase probes the environment's causal dynamics *before*
task execution, building an **in-context world model** (no weight updates); WebArena multi-site 2%→23%.
**Verdict: PARK, EWM/exploration line.** This is a **fully test-time, in-regime** statement of "explore-to-
build-a-world-model-then-act" — the same shape as OPINE-World's online model synthesis but lighter (in-context,
no code synthesis, no CEGIS). Parked, not adapted, for two reasons: (i) the 2%→23% jump is on web-navigation
where a short probing phase maps a *stable* site; ARC-AGI-3 games have per-game novel dynamics and our binding
constraint is depth on the frontier, not a cold-start exploration deficit the duck-fork already handles; (ii)
"probe-before-act" spends the action budget that the depth lane is trying to concentrate on the solve. Keep as
a reference for the EWM-contract exploration framing if/when banking re-opens; no build now.

## Executable world models / OPINE-World watch [standing]

**OPINE-World (2607.01531) follow-ups: one, already in-set.** The only new citing work is **2607.15439**
("Do Coding Agents Need Executable World Models, Simplification, and Verification…") — this is the
**Rodionov team's own ablation follow-up, already a standing exclusion**; it nests four Codex agents (textual
baseline → flexible-interface EWM → +scheduled simplification → +fixed-interface exact-replay verification)
across gpt-5.4/5.5/5.6-sol at high/xhigh/max. Robust finding: **every variant improves with stronger model +
more reasoning effort** — i.e. the ablation cannot cleanly attribute the gain to EWM-vs-simplification-vs-
verification because model/effort dominates. **Verdict: IGNORE (already processed as exclusion).** Worth one
mental note: this is the *second* independent Jul result (with Opus-5) saying **model capability + reasoning
effort is the dominant lever on ARC-AGI-3** — corroborates the A17 model-swap thesis over harness micro-tuning.
No independent OPINE-World reproduction.
