## 3. FATAL findings — what actually changed today

**Six FATALs** were filed across the five reviews (methodology filed two); total MAJOR count 27.

independently by two reviewers each. All were verified against repo data, not asserted.

### 3.1 The binding resource is WALL CLOCK, not actions *(rl-planning + systems, independently)*

`runs/kernel_pulls/war_eval_v1/benchmark.json`: all 25 games ended at **7920.2–7939.9 s**, against
a configured `max_runtime_s_per_game=7920.0` with `max_actions_per_game=None`. Systems confirms on
a second pull (198,069 s and 198,115 s / 25 games ≈ 7,923 s). **All 50 game-runs were cut by the
wall-clock guillotine; the action cap was never approached.** ≈54 s per scored action.

Consequences, accepted:
- §2.3's "in-sandbox reasoning costs zero scored actions, therefore a persistent namespace is
  doubly attractive" is **false on our measurement rail**. In-sandbox reasoning is paid in
  latency — the same channel as R23's NC-14 mechanism-null.
- `actions_per_level_completed` as framed is **not** a legitimate co-primary. The metric homework
  closed 08-08 was right about the Kaggle metric and wrong about our rail.
- §6.2's Δlc gate **cannot separate "harmful" from "slower."** P1 could die on latency and be
  recorded as a mechanism negative — which would be the **fourth** lane death by that route.
- **Required before any P1 screen:** latency instrumentation + a matched-action-prefix secondary
  endpoint. Both free.

### 3.2 The inherited non-harm gate fails a true null half the time *(methodology)*

Measured on the 90 null-vs-null pairs in `runs/null10` (10 identical vanilla runs × 25 games):
mean-Δlc leg FPR **12.2%**, worst-game leg **50.0%**, conjunction **51.1%**. A −2 on some game is
the **modal null outcome**. Provenance is separately broken: −0.128 was war-v1's *non-significant*
observed harm (sign-flip p=0.9495), estimated against a 10-run-averaged baseline but applied
against a single run (per-game Δ sd 0.392 → 0.699).

**"Inherited verbatim" was rhetorical** — the digit transported, the calibration did not. This is
the most consequential finding of the round because that gate is what the campaign has been
killing lanes with. **Recalibration is running now** (independent reproduction commissioned —
see §5.1); no future screen may use the old gate.

### 3.3a POST-PANEL — the A22 death record is VACATED *(verified independently by the campaign lead)*

The recalibration commissioned under §5.1 reproduced **every** null-calibration digit
(mean-leg type-I 12.22%, worst-leg 50.00%, conjunction 51.11%; null sd 0.1223; worst-game null

**A22 v2.1's headline harm — mean Δlc −0.360, worst-game −2 — is bit-for-bit `war_eval_v3 −
war_eval_v1`, with no compaction in either run.** The number that killed the lane is reproduced

Bonus provenance finding: **−0.128 is an arithmetic identity, not a statistic** — (12 − 15.2)/25,

**RULING: the A22 compaction lane is UNRESOLVED, not DEAD.** Three K3 strikes were recorded by a

inflation is **1.28×** on the decision statistic (1.34× per-game = theory √(2/(1+1/9))), not 1.78×

**every** baseline size m=1…9, the primary defect was the **number**, not only the procedure. Note
the worst-game leg gets *worse* under an averaged baseline (60%), because a fractional baseline
slips under −1.0 trivially.

**Binding consequences:**
- **No screen may use the old K3.** Every arm ever paused or killed on it is suspect.
- **Every arm needs m ≥ 3 same-config baseline runs before it can be screened at all.** This is a
