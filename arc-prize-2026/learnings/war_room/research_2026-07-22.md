## ARC-AGI-3 direct — Schema harness (THE item)

**Schema: "Frontier Models with Our Harness Achieve ~99% on ARC-AGI-3 Public"** (Impossible Research,
released Jul 16-2026; [site](https://schema-harness.github.io/),
[HF traces](https://huggingface.co/datasets/schema-harness/arc-agi-3-schema-traces),
[HN](https://news.ycombinator.com/item?id=48935905)).
Claims: **Claude collection (Opus 4.8 + Fable 5): 25/25 games, 183/183 levels, mean RHAE 98.98%**;
GPT-5.6 Sol collection: 24/25 games, 182/183 levels, 95.35%. Compare official verified frontier: 13.33%
public / 7.78% semi-private (GPT-5.6 Sol), and Rodionov's 58.12% RHAE public SOTA.
Method (from release coverage; no paper yet): **world model as an executable program, not a vector** —
inverse graphics (parse observations into symbolic state) then inverse dynamics (induce transition rules);
the induced **step function + goal predicate are *certified* by replaying them against the full interaction
history**; only once certified does the agent run **BFS over thousands of simulated states at zero
environment-interaction cost**. Plus a fixed fallback rule: Opus 4.8 / Sol-xhigh run first; games scoring
<80 are rerun with Fable 5 / Sol-max and the per-game max is kept.
Caveats (real): self-reported, **public set only, not verified by ARC Prize**; Kamradt objects that the
fallback rule violates benchmark spirit and that human intelligence may be baked into the harness; AERA
(2605.25931) already argued the public 25 are heuristic-solvable — 99% public says little about private,
which is exactly our generalization-first stance. RHAE is also not the Kaggle metric and their model stack
(Opus 4.8 API) is unusable in our zero-budget offline runtime.

**Verdict: ADOPT (trace mining + contract confirmation), EWM line (4) + harness line (3).**
Two zero-budget extractions:
1. **Mine the 50 released trajectories** (768 MB; `run.json`, streamed `events.jsonl`, snapshots,
   `score_trajectories.py`, per-game `evaluation_results.csv` + human `baseline_actions.csv`). Specifically:
   how does Schema behave in the first N turns of the games where *our* EWM aborts at step 0 from state
   aliasing (wa30/sc25-class)? The event logs should show their observe→model→certify→plan phase structure
   and turn expenditure per phase. This is free local analysis and directly informs EWM contract v1.1.
2. **Certification-against-history IS the resync mechanism we were looking for.** In Schema's contract the
   current latent state is recovered by replaying the action history through the certified step function,
   and state aliasing manifests as a *certification failure* (predicted trace diverges from observed trace)
   — a signal to revise the model / re-observe, never a step-0 abort. This is the strongest external
   confirmation yet of the resync-before-abort ordering (and of AgentAbstain's verify-before-act from
   yesterday): **abort is only legal after certification fails post-revision, not before planning starts.**
Secondary (harness/budget, line 3): the **escalate-on-low-score fallback rule** (cheap config first, rerun
only failing games with the expensive config, keep per-game max) is a clean template for the A17 wall-closer
economics — 27B harness first, 72B only on games below bar. Note for the ledger, no build this cycle.

## Latent-state / partial observability (EWM step-0 abort) — one real ADAPT

**Ask the World Before Acting: Environment Probing for Calibrated Agent World Models (EnvProbe)**
([arXiv:2606.31422](https://arxiv.org/abs/2606.31422), Jun 30, rev Jul 5) — formulates belief verification
as a **budgeted probing problem**: before acting, the agent may query one belief field, paying one
interaction. EnvProbe scores which belief to verify by task criticality, staleness, verbalized uncertainty,
and dependency structure; +6.45 pts overall vs periodic probing (+11.76 on tool-dependency tasks). Key
negative finding: **agent self-reported uncertainty is unreliable when the agent is confidently wrong**.
**Verdict: ADAPT (medium), EWM line (4).** This is the probe-selection half of resync-before-abort: when
certification fails on an aliased game, don't re-observe blindly — spend the probe on the belief field with
highest criticality×staleness (for wa30/sc25 aliasing, the phase variable). And the negative finding
independently validates our sentinel design choice of **deterministic observables over model-verbalized
confidence** as the gate signal. Feeds EWM contract v1.1 §probe-policy; no standalone build.

**Agent-BRACE: Decoupling Beliefs from Actions via Verbalized State Uncertainty**
([arXiv:2605.11436](https://arxiv.org/abs/2605.11436), May 12, Bansal group) — separate belief-state model
(atomic NL claims, each with ordinal certainty certain→unknown) from policy model, jointly RL-trained;
+14.5% abs (Qwen2.5-3B), near-constant context vs episode length.
**Verdict: PARK.** The gains come from RL joint optimization — out of the no-weight-update Kaggle regime.
The liftable residue is the **belief format** (atomic claims + ordinal certainty labels) as an output schema
for the latent-state audit; note and move on.

**ASK in the Dark: Uncertainty-Gated LLM Assistance under Partial Observability**
([arXiv:2607.02686](https://arxiv.org/abs/2607.02686), Jul 2) — RL agent + SLM consultant; predictive
entropy (action uncertainty) stays informative in POMDPs; prompt design dominated model scale.
**Verdict: IGNORE.** RL-agent-with-LLM-advisor topology is not ours; the prompt-dominates-scale finding is
exactly the axis feedback_prompt_is_noise tells us not to iterate on.
