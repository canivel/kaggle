# Research Sweep — 2026-07-16

Context: warpack shipped; ledger+escalation awaiting compound gate; perception pack staged. Gate statistic = Δlevels_completed; only per-draw mean gains matter (order-stats ceiling ~1.11@k=110).

## ARC-AGI-3 direct

**GPT-5.6 Sol frontier result** ([arcprize.org](https://arcprize.org/results/openai-gpt-5-6-sol), [benchlm.ai](https://benchlm.ai/benchmarks/arcAgi3)) — Sol @ max reasoning: 13.33% public / 7.78% semi-private; first model to *win* a public game — **ft09 at 87%**. **ADAPT**: ft09 is our highest-variance game (build-rail sd 0.572, ft09=54%); Sol shows ft09 is fully solvable — mine any published traces/commentary for ft09 mechanics rather than treating it as a lottery.

**Explore Before You Solve: Speed–Depth Trade-off in Epistemic Agents for ARC-AGI-3** ([arXiv:2605.25931](https://arxiv.org/pdf/2605.25931)) — explicit explore-then-exploit budget split. **IGNORE**: warpack already implements phase-split exploration; late-May, already absorbed in war-era design.

## Hypothesis-tracking / memory

**OCM: Object-Centric Environment Modeling** ([arXiv:2607.02846](https://arxiv.org/abs/2607.02846), Jul 3) — experience → executable Python object classes + verified reusable procedures, updated online after each episode; best avg rank, fewer invalid actions. **ADAPT**: strongest match to our generalization-first priority; the "verified procedure bank" idea maps onto the staged perception pack + ledger — consider storing warpack rules as executable checks, not prose. Candidate for post-gate iteration only.

**Speculate with Memory** ([arXiv:2607.12236](https://arxiv.org/abs/2607.12236), Jul 14) — speculator with contrastive transition table + episodic memory + confusion tracker; 19–39% action-prediction gains. **ADAPT (one component)**: the *confusion tracker* (suppress recurring failed actions) is a cheap ledger extension; speculation itself is inference-speed machinery we don't need. Hold behind compound gate.

**PABU: Progress-Aware Belief Update** ([arXiv:2602.09138](https://arxiv.org/pdf/2602.09138)) — belief updates gated on progress signal. **IGNORE**: Feb paper; our ledger already conditions on level/score progress.

## Test-time learning

**aTTT: Agentic Test-Time Training** ([arXiv:2607.03441](https://arxiv.org/pdf/2607.03441), Jul 3) — LoRA weight updates during long episodes with repeated-n-gram downweighting; +5.0 ALFWorld. Fixes drift/repeated-action loops. **IGNORE for now**: requires vLLM LoRA serving in-kernel; zero-budget rule + Kaggle runtime makes weight-update TTT impractical; our escalation ladder targets the same repeated-failure symptom prompt-side.

**From Player to Master: RL over Memory** ([arXiv:2606.08656](https://arxiv.org/html/2606.08656)) — trains cross-game memory evolution end-to-end. **IGNORE**: needs training loop we can't run under zero-budget; direction validates ledger-across-draws concept.

## Qwen3 agentic

**Qwen-AgentWorld: Language World Models** ([Qwen team, arXiv:2606.24597](https://arxiv.org/abs/2606.24597), Jun 24; [GitHub](https://github.com/QwenLM/Qwen-AgentWorld)) — next-state-prediction warm-up before acting; +8.66 over Qwen3.5-35B baseline. **ADAPT (prompt-side only)**: "simulate the next frame before committing" as a one-line escalation-tier instruction is free and gate-testable; model swap itself is IGNORE (weights too heavy for our kernel).

## Bottom line
Nothing overturns the plan. Two cheap, gate-compatible adds: (1) confusion-tracker field in ledger, (2) predict-next-frame instruction in escalation tier. One medium bet post-gate: OCM-style executable rule bank. Priority signal: ft09 is winnable — study Sol's ft09 behavior.
